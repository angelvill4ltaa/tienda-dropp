# DROPP - Aplicación Web Ecommerce

DROPP es una aplicación web ecommerce full stack desarrollada para simular una experiencia de compra moderna con autenticación de usuarios, carrito dinámico, checkout seguro, procesamiento de órdenes y almacenamiento en base de datos.

Proyecto creado como parte de mi portafolio profesional para demostrar desarrollo frontend, backend y conexión con base de datos en un entorno real.

---

## Tecnologías Utilizadas

### Frontend

* React.js
* Tailwind CSS
* React Router DOM
* Context API
* Lucide React

### Backend

* Node.js
* Express.js

### Base de Datos

* MySQL

### Otras Herramientas

* Git & GitHub
* Visual Studio Code

---

## Estructura del Proyecto

/client -> Frontend
/server -> Backend
MySQL -> Base de datos

---

## Instalación

Clonar repositorio:

```bash
git clone https://github.com/angelvill4ltaa/tienda-dropp
```

Frontend:

```bash
cd client
npm install
npm start
```

Backend:

```bash
cd server
npm install
node index.js
```

---

## Funcionalidades

* Catálogo dinámico de productos
* Sistema de autenticación de usuarios
* Carrito de compras interactivo
* Checkout con validación de pago
* Registro y procesamiento de órdenes
* Libro de Reclamaciones digital
* Diseño responsive moderno
