# DROPP

Aplicación web ecommerce full stack enfocada en una experiencia de compra moderna. Proyecto desarrollado para demostrar desarrollo frontend, backend y base de datos en un entorno real.

## Tecnologías 

### Frontend

* React.js
* Tailwind CSS
* React Router DOM
* Context API

### Backend

* Node.js
* Express.js

### Base de Datos

* MySQL

## Instalación

```bash
git clone https://github.com/angelvill4ltaa/tienda-dropp
```

Frontend:

```bash
cd client
npm install
npm start
```

Backend:

```bash
cd server
npm install
node index.js
```
